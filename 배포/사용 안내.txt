가려줘 1.0.0
제작: 가정재연쌤 (@gajae_ssam)
키링을 당기면 지금 쓰던 창을 블라인드로 가려 주는 프로그램이에요.


■ 실행하기
  가려줘.exe를 더블클릭하세요. 설치는 필요 없어요.
  화면 맨 위에 곰돌이 키링이 매달리면 준비 끝!

  ※ 처음 실행할 때 파란 창 "Windows의 PC 보호"가 뜰 수 있어요.
     인터넷에서 받은 프로그램이라 뜨는 안내예요.
     [추가 정보] 를 누른 뒤 [실행] 을 누르면 돼요.

  ※ 가려줘.exe는 바탕화면이나 문서 폴더처럼 계속 둘 곳에 옮겨 두고 쓰세요.
     (다운로드 폴더에 두면 정리하다 지워질 수 있어요)


■ 사용법
  🐻 키링을
     클릭           →  다 가려요
     아래로 당기기  →  내려와요
     위로 올리기    →  올라가요

  가릴 창을 먼저 클릭하세요.
  키링을 옆으로 드래그해서 옮길 수 있어요.
  우클릭하면 메뉴가 나와요.
     꾸미기  : 키링 크기, 줄 길이, 줄 색, 키링 캐릭터 바꾸기
     설정    : 말풍선 안내, 컴퓨터 켤 때 자동 실행
     사용법 / 종료


■ 컴퓨터 켤 때 자동으로 켜기
  키링 우클릭 → 설정 → [컴퓨터 켤 때 자동 실행] 을 누르세요. (체크되면 켜진 거예요)
  다시 누르면 꺼져요.


■ 키링이 안 보일 때
  - 블라인드가 내려와 있으면 키링은 블라인드에 달려 있어요.
  - PPT 슬라이드쇼처럼 전체 화면일 때는 키링이 숨어요.
    마우스를 키링 자리(화면 위쪽)로 가져가면 다시 나타나요.
  - 그래도 못 찾겠으면, 작업 표시줄 오른쪽 곰돌이 아이콘을 더블클릭하세요.
    키링이 처음 자리로 돌아와요.
    (아이콘이 안 보이면 작업 표시줄의 ^ 를 눌러 보세요)


■ 끄기
  키링 우클릭 → 종료
  또는 작업 표시줄 오른쪽 곰돌이 아이콘 우클릭 → 종료


■ 새 버전으로 바꾸기
  1. 가려줘를 끄세요.
  2. 새로 받은 가려줘.exe로 원래 파일을 바꿔 끼우세요. (같은 자리에 덮어쓰기)
  3. 다시 실행하면 끝! 키링 꾸미기와 설정은 그대로 남아 있어요.

  지금 쓰는 버전은 키링 우클릭 → 사용법 창 맨 아래,
  또는 작업 표시줄 곰돌이 아이콘 우클릭 메뉴 맨 위에서 볼 수 있어요.


■ 컴퓨터에서 지우기
  1. 자동 실행을 켜 두었다면 먼저 끄세요. (키링 우클릭 → 설정)
  2. 가려줘를 끄세요.
  3. 가려줘.exe 파일을 지우세요.
  4. 설정까지 지우려면 아래 폴더를 지우세요.
     %AppData%\Garyeojwo
     (파일 탐색기 주소창에 그대로 붙여 넣으면 열려요)


■ 필요한 환경
  Windows 10 / 11
