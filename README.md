# 🐻 가려줘

키링을 당기면 지금 쓰던 창을 블라인드로 가려 주는 Windows 프로그램이에요.
시험 문제, 정답 화면처럼 잠깐 가려야 하는 창을 귀엽게 가릴 수 있어요.

제작: 가정재연쌤 (@gajae_ssam)

## 다운로드

오른쪽 **Releases**에서 `가려줘.exe`를 받으세요. 설치는 필요 없어요.

> 처음 실행할 때 파란 창 "Windows의 PC 보호"가 뜰 수 있어요.
> 인터넷에서 받은 프로그램이라 뜨는 안내예요. **[추가 정보] → [실행]** 을 누르면 돼요.

## 사용법

화면 맨 위에 매달린 🐻 키링을

| 동작 | 결과 |
|---|---|
| 클릭 | 다 가려요 |
| 아래로 당기기 | 내려와요 |
| 위로 올리기 | 올라가요 |

- 가릴 창을 먼저 클릭하세요.
- 키링을 옆으로 드래그해서 옮길 수 있어요.
- 우클릭하면 메뉴가 나와요.
  - **꾸미기**: 키링 크기, 줄 길이, 줄 색, 키링 캐릭터 바꾸기
  - **설정**: 말풍선 안내, 컴퓨터 켤 때 자동 실행

자세한 안내는 [사용 안내.txt](배포/사용%20안내.txt)를 보세요.

## 필요한 환경

Windows 10 / 11 (.NET Framework 4.x, 윈도우에 기본으로 들어 있어요)

## 직접 빌드하기

별도 설치 없이 윈도우에 들어 있는 C# 컴파일러로 빌드해요.

| 파일 | 하는 일 |
|---|---|
| `build.bat` | 배포판 `가려줘.exe`를 만들고 `배포` 폴더에 복사 |
| `build-dev.bat` | 개발용 `가려줘_dev.exe` (미리보기·자동 점검 기능 포함) |
| `tools\make-icon.bat` | 곰돌이 그림으로 `assets\app.ico` 다시 만들기 |

## 폴더 구성

```
src/      프로그램 소스 (C#, WPF)
assets/   아이콘
tools/    아이콘 만드는 도구
배포/     배포할 때 함께 주는 사용 안내
```

설정은 `%AppData%\Garyeojwo` 폴더에 저장돼요.
